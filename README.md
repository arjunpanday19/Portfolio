## ✨ Features

- **Dynamic Hero Section:** Implements a premium typewriter typing effect listing multiple engineering and developer roles.
- **Interactive Background:** Utilizes `react-tsparticles` for a beautiful, physics-based, interactive particle network that reacts to cursor hover and clicks.
- **Toggleable Theme:** Sleek global state dark/light mode system with custom smooth transitions.
- **Smooth Navigation:** Multi-section smooth scrolling (`react-scroll`) with a floating premium glassmorphism navbar.
- **Professional Experience Timeline:** Interactive vertical timeline detailing internships at **NIELIT**, **IBM**, and **DUC/ShapeMySkills**.
- **Project Showcase:** Highlights major full-stack and predictive systems like **Aurelyf Care** (Smart Heart Attack Prediction + Booking) and **Zayka Express** (Food Ordering platform) with live links.
- **Certificates Slider:** Elegant layout displaying certifications from Apna College, IBM, and ShapeMySkills.
- **Functional Contact Form:** Beautiful interactive contact form with dynamic state handling, validation, and layout.

## 🛠️ Technology Stack

- **Core Framework:** [React.js](https://react.dev/) (v19)
- **Bundler:** [Vite](https://vite.dev/) (v8) for ultra-fast Hot Module Replacement (HMR)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (v4.0) for modern, utility-first fluid design systems
- **Animations:** [Framer Motion](https://www.framer.com/motion/) for fluid page entries and interactive micro-animations
- **Effects:** `typewriter-effect` & `react-tsparticles` for rich visual aesthetics

## 🚀 Getting Started Locally

Follow these steps to run the portfolio on your local machine:

### 1. Clone the repository
```bash
git clone https://github.com/arjunpanday19/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view your site!

### 4. Build for production
```bash
npm run build
```
The production bundle will be generated in the `dist/` directory.

---

## ☁️ Deployment on Vercel

The portfolio is fully optimized for one-click deployment on **Vercel**:

1. Go to [vercel.com](https://vercel.com/) and click **Add New > Project**.
2. Import the `arjunpanday19/Portfolio` repository.
3. Keep the default build settings (Vercel automatically detects the **Vite** preset).
4. Click **Deploy**!
